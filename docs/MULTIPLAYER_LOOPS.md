## 1. 狩獵場（Hunting Grounds）

### 定位

黑焰溢地邊陲的 **星途獵場**——不是主線地圖。  
重複刷材料、養每日循環；日後可開多人房。

### 解鎖

- 進入騎士堡後（`c1_entered_city`）  
- 輿圖／六域岔路「狩獵場」入口  

### 單人規則（v1 · 已實作）

| 項 | 規格 |
|----|------|
| 每日有獎場次 | **5**（`HuntSystem`） |
| 每場結構 | **3 波**雜魚（灰燼鼠 → 殘兵 → 焰靈） |
| 中途敗北 | 當波無獎；已過波次保底材料×0～1 |
| 通關獎勵 | 金 + 狩獵材料 + 機率藥水 |
| 用盡後 | 可「練習」：金×0.35、材料稀少 |

### 掉落（可交易預留）

| id | 名 | 說明 |
|----|----|------|
| `hunt_hide` | 溢皮 | 基礎材料，可賣／未來市集 |
| `hunt_bone` | 焰骨 | 中階 |
| `hunt_core` | 溢核 | 稀有，日 cap 內有限 |

### 多人（v2 · 0.10.1 已實作）

- 狩獵房 `mode=hunt`：2～4 人；**房主**打 3 波  
- 通關共領金＋溢皮／焰骨（人數加碼）  
- 日 cap 仍看房主本機 `HuntSystem`  
- 單人仍可進；可帶離線助戰

## 2. 交易 · 星途市集（0.10.0）

### 定位

非同步掛單，**不做**即時面對面討價。

### 可交易

- 狩獵材料、一般消耗品溢出  
- `tradeable` 標記物  

### 不可交易

- 主線關鍵進度物  
- 秘境唯一魂器  

### 規則

- 手續費 **8%**（售出時從貨款扣）  
- **離線**：NPC 陰影庫（日刷）＋本地掛單  
- **上線**：`market_listings` + `market_buy` RPC + `market_credit`  
- 溢物回收仍可即時賣金  

### 入口

騎士堡廣場／下城市集／行商驛站／獵場「星途市集」· 暫停選單

## 3. 組隊挑戰 Boss（0.10.0）

### 內容池

| 本 | 來源 |
|----|------|
| 裂縫四套 | `RiftSchedule` |
| 秘境再臨 | 疤主／鏡影／船長加強（後） |
| 歲旅限定 | 活動月加權（後） |

### 規則

- 2～4 人；**1 人可開**  
- **房主跑 BattleSim**；成員待機  
- 通關後全員可領共鬥獎（人數加成）  
- 房內人數給房主攻／防加成  
- 主線 Boss **不**改組隊  

### 同步

輪詢 2.5s（HTTP）；非即時同屏按鍵。  
房間代碼 6 字、列表加入。  

### 離線助戰（仍保留）

- 「星途助戰」0～2 假旅人  
- 無後端時裂縫仍可玩
