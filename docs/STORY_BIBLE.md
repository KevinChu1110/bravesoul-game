# STORY BIBLE · 主線節拍

> 目標：3 個月能通關的完整情感弧；6 個月加厚支線與域內容。  
> 主題：**不慕強權的心，比最強的野心更靠近光。**

## 主角

| 項 | 內容 |
|----|------|
| 身分 | 純白之兔（可自訂毛色基礎款）；外號由 NPC 給予 |
| 能力起點 | 連劍都快拿不穩 |
| 內在需求 | 保護具體的人／地方，而非「變強稱霸」 |
| 外在目標 | 查明黑焰、通過試煉、阻止塔封崩解 |
| 弧光 | 害怕 → 承擔 → 理解聖獸之痛 → 拒絕魔王的「變強」誘惑 → 仍選擇守護 |

**出村動機（定稿草案，可改）：**  
村子被黑焰餘燼點燃之夜，重要之人（P0 NPC「麥穗」或親人）受傷／失蹤。主角不懂預言，只知道不能再逃。鏽劍是那夜撿起的物件，之後由騎士域鐵匠重鍛為「真正的第一把武器」——讓武器成長綁敘事。

## 反派與對立

| 角色 | 欲望 | 與主角關係 |
|------|------|------------|
| 魔王 | 崩封、以野心為食扩张 | 最終試煉；途中以幻聲誘惑 |
| 黑焰 | 規則本身 | 感染配角、製造道德灰區 |
| 異化聖獸 | 被放大的「勇／疾／智／力／道」 | 必須戰鬥才能喚醒；醒後託付 |
| 人類野心者（可選） | 想借用黑焰變強 | 中段鏡子戰／支線 |

## 三幕結構（主線）

### 第一幕 · 微末的白（起）

- 序章：火災之夜、撿劍、離村  
- 抵達騎士堡壘外緣，認識**老門衛**與**鐵匠**  
- 學習世界規則（黑焰、聖獸、預言的民間版本——互相矛盾）  
- 第一場即時戰鬥教學（弱狼／黑焰渣滓）  
- **雷歐戰**：打醒第一支柱；獲「騎士承認」與金鬃契機  
- **轉折**：得知五柱皆危，塔下黑焰在漲；有人勸退「一隻兔子別去送死」

### 第二幕 · 五域之路（承／轉）

**3 個月最短路徑（必打通）：**  
騎士域（完整）→ 自選再完整做 **2 域**（建議：忍者村「看破」+ 道場「為何而戰」情感強）→ 其餘域用「旅途蒙太奇＋簡圖＋小戰」交代支柱鬆動 → 塔。

**6 個月完整路徑：** 六域皆可遊玩，順序大致自由但建議敘事錨點：

| 順序建議 | 域 | 情感課 | BOSS 醒後一句 |
|----------|-----|--------|----------------|
| 1 | 騎士堡壘 | 勇氣≠體型 | 真正的騎士不退縮 |
| 2 | 遊俠森林 | 快與等待 | 你追上了風 |
| 3 | 忍者村 | 真實與自我 | 霧散了，路在眼前 |
| 4 | 維京海岸 | 力量的用途 | 站到最後的是你 |
| 5 | 武鬥道場 | 為何而戰 | 你的拳裡有道了 |
| 6 | 法師之塔 | 拒絕成為魔 | 不可能……兔子…… |

**中段情感錨（R2 定案 · 填爆點空窗）：**  
C2 休息點（營火／霧隱村客棧）觸發 **N8 延遲的信**——見下節。  
給玩家「繼續走」的**個人理由**，不只救世界。

**中段世界壓（可輕）：**  
霧隱或星讀透露封印再撐不久；主角可短怕，仍前進。

### 第三幕 · 塔與晨光（合）

- 塔下營地：生還者、懼怕者、最後的物資與道別  
- 塔內：層層回憶／試煉（可短）——映照五域學到的「心」  
- **主反轉（定案，通關前約 20～40 分鐘揭露，再打最終戰）**  
- **魔王戰**：三拒誘惑；形態剝落；時機必殺可復用格擋  
- 終章：黑焰潰散、聖獸化星、晨光；兔子仍是兔子，但世界記得  
- 解鎖星辰兔等通關證明（外觀／典籍）

## 主反轉與伏筆（2026-08 定案）

> 只要**一個**下巴掉下來的時刻，服務主題，不搞廉價騙術。  
> 評析見 DESIGN_CRITIQUE.md。

### 主反轉 · 魔王是「第一位至弱者」

**揭露時機：** C6 塔中層，最終戰**之前**（讓玩家帶著震撼打完）。

**內容：**  
無名魔王並非純粹外來惡。祂曾是第一位應驗預言、走到塔頂的「至弱者」。  
為了讓五柱封印再撐千年，祂在絕境中接受了黑焰——以**野心與力量**為薪柴維持封印。  
「變強」成了祂守護世界的方式；黑焰與魔王之名，是代價寫在臉上的結果。  
預言沒寫錯「至弱能至塔頂」；寫漏了：**若至弱也開始慕強，塔仍會立，心會先死。**

**主角的路：**  
拒絕三度誘惑（力量／復仇／安穩），不是天真，而是證明存在**另一條守護**：  
不靠吞噬野心，靠不退縮的心與眾生的連帶（聖獸清醒、NPC 旗幟）。

**最終戰讀法：**  
你不是在殺「絕對他者」，而是在解放一個走錯代價的前輩；終段其外形逼近「舊至弱者」殘影。

### 副伏筆 · 鏽劍／微末之刃

- 鏽劍芯鐵有古紋；釘釘重鍛時沉默片刻：「……別弄丟。」  
- C2～C3 典籍碎片：「第一位持微末之刃者，再未歸村。」  
- 塔中與魔王殘影／劍共鳴時接上主反轉。  

### 明確不用的反轉

| 方案 | 原因 |
|------|------|
| 麥穗其實已死、全程幻覺 | 破壞溫度與玩家對世界的信任；與「等待／重逢」人格衝突 |
| 多重結局大改 | 時程與敘事成本；用 2～3 次小選擇即可 |

### 麥穗線（維持溫度）

- 可傷、可失聯、可塔下重逢或一封長信。  
- 可「差點沾焰」灰線，由主角／星讀拉回。  
- **不是**假人幻覺。

### N8 · 延遲的信（3m 必做 · 中段錨）

| 項 | 內容 |
|----|------|
| 時機 | **C2** 進入忍者村後第一次安全休息（客棧／營火），主線自動或強制調查 |
| 形式 A（優） | 碎／未碎麥稈裡捲著紙條（若桿已碎：行囊縫裡掉出） |
| 形式 B | 星讀／霧隱代交「遲到的信」 |
| 正文（定稿） | **「我還在。不是因為預言，是因為你還沒回來。」** |
| 系統 | 寫入日誌；可截圖；無新系統 |
| flag | `flag.c2_wheat_letter = true` |
| 回收 | 終章麥穗重逢／書信可呼應「還在啊」 |

## 玩家選擇（輕量）

- 不做龐大多結局 RPG；做 **2～3 次有記憶點的對話選擇**（影響 NPC 去向或一句終章差異即可）。  
- 主線結局**核心相同**（魔王敗、晨光），支線決定「誰站在塔下送你」「某鎮重建與否」。

## 敘事呈現規格

- 對話：場景內泡泡／半身立繪，可略過已讀  
- 重要戰前：短演出（不鎖操作超過 30 秒可 skip）  
- 典籍：可選閱讀，不擋進度  
- 戰鬥中：技能名、BOSS 怒吼可飛字，不蓋關鍵操作  

## 與連線的敘事接口

- 其他玩家 = 世界觀中的「星途旅人」／命運殘影  
- 主線過場**不**插入強制多人  
- 共鬥是「塔外裂縫溢出的災厄」等可選事件，不寫進通關必要條件
