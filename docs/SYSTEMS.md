## 4. 三重養成（定稿）

> **鐵匠養器 · 星途養魂 · 旅途養招。**

| 軸 | 系統 | 3m 範圍 | 主掛 NPC |
|----|------|---------|----------|
| **器** | 裝備鍛造／升階 T1–T8+ | 武器+防具；失敗不掉階 | 釘釘 |
| **魂** | 聚魂、入魂、拆魂 | 1～2 槽；基礎星與品質 | 星讀 |
| **招** | 技能習得＋**技能升級** | 劍系為主 Lv1–3 | 灰鬚、域導師 |

三者正交分工見 [PROGRESSION.md](PROGRESSION.md)。  
**不是**三選一；**是**三軸都做，曲線錯開、UI 空間分離。

### 為何戰魂「像」裝備升級卻仍分開
- 器階：同一件的穩定養成、保底、綁外觀階。  
- 戰魂：運氣與 build 個性、可拆換、聚魂演出。  
玩家若混淆 → 檢查 UI 用詞（[UI.md](UI.md)）。
