# 十萬字世界故事 × 遊戲內敘事 × Short 共進

> 目標：寫 **10 萬字以上**完整劇情，**進遊戲**，再**翻拍成 Short**；  
> 隨「玩家進度／社群進度」推進，製造**陪同感**（不是被劇透感）。

---

## 0. 一句話定調

| 層 | 是什麼 | 不是什麼 |
|----|--------|----------|
| **世界小說（Novel Layer）** | 完整 10 萬字+ 的翠嶺故事聖經 | 不是一次性塞進對話框 |
| **遊戲敘事（Play Layer）** | 場景、旗幟、短對白、關鍵演出 | 不是電子書閱讀器 |
| **週更 Short（Feed Layer）** | 小說／遊戲的**公開切片** | 不是搶先爆完全結局 |

三層**同源**：同一章同一事件，三種密度。

---

## 1. 為什麼這招適合勇者之魂

- 已有章節骨架：**C0 序章 → C1 騎士／雷歐 → … → C6 塔／魔王**（見 `STORY_BIBLE`、`SCRIPT_C*`）
- 基調是「不慕強權的兔子」——**適合連載共情**，不是純數值秀
- 你已有：Veo 產片、12 週 Short 表、官網 CTA  
- 缺的是：**可連載的長文骨架 + 三層同步規則**

陪同感公式：

```
玩家本週打到雷歐前後
  ≈ Short 本週發「獅子那一擊」
  ≈ 官網／社群連載發「同章節選段」
→ 「我們跟兔子同一週在過這件事」
```

## 2. 10 萬字怎麼拆才寫得完、也用得上

### 2.1 體量建議（約 10～12 萬字）

| 區塊 | 字數約 | 對應遊戲 |
|------|--------|----------|
| 序：餘燼與拾劍 | 0.8～1.2 萬 | C0 |
| 第一部：騎士域與獅子 | 1.5～2 萬 | C1 |
| 第二部：霧與影 | 1.5～2 萬 | C2 忍者／白霧 |
| 第三部：弓與風 | 1.2～1.8 萬 | C3 遊俠／疾影 |
| 第四部：拳與石 | 1.2～1.8 萬 | C4～C5 道場／石拳 |
| 第五部：星與塔 | 1.5～2 萬 | C6 前半 |
| 終部：不慕強權 | 1.2～1.8 萬 | C6 魔王／終章 |
| 間章／外傳／NPC 側寫 | 1～2 萬 | 支線、旗幟、Short 用 |

**原則**：主線可獨立通讀；外傳可當 Short 補丁，不擋主線。

### 2.2 寫作單位：場景卡（Scene Card）

每一千字～兩千字對應一張卡，方便進遊戲與翻拍：

```
ID: C1-S07
章: 騎士域
場景名: 鍛造屋的第一夜
遊戲觸發: 進釘釘店 / flag c1_forged
小說字數: ~1200
遊戲對白: 3～6 句（從小說壓）
Short 週次: 可對 W4 / W9
可公開: 是（無結局雷）
鉤子一句: 「失敗了？階還在。」
```

10 萬字 ≈ **60～100 張場景卡**，比「一篇超長文」好管理。

### 2.3 寫作節奏（可持續）

| 節奏 | 量 | 說明 |
|------|-----|------|
| 日常 | 800～1500 字／日 | 或一週 2 個完整場景卡 |
| 週 | 完成 1 遊戲節拍 + 1 Short 可用選段 | 與 12 週表對齊 |
| 月 | 鎖定一部（約 1.5～2 萬）定稿 | 可進遊戲的才算「完成」 |

**不要**：先寫完 10 萬再進遊戲（半年無內容）。  
**要**：**一卷定稿 → 進遊戲一章 → 發 2～4 支 Short → 再寫下一卷**。

## 3. 怎麼「放到遊戲故事內」（實作分層）

### 3.1 遊戲裡只放「可玩密度」

| 內容類型 | 遊戲內形態 | 字數感 |
|----------|------------|--------|
| 主線關鍵 | 過場對白 `dialogues/*.json`、旗幟 | 極短 |
| 章節記憶 | **旅途手札／故事圖鑑**（可新系統） | 中（300～800 字／條） |
| 完整小說 | **可選閱讀**（圖鑑「全文」或官網連載） | 長 |
| 環境 | 物件 flavor、NPC 閒聊 | 一句～一段 |

玩家**永遠不被強迫讀完小說**；但走完章節會**解鎖**對應手札／選段 → 有收集感與陪同感。

### 3.2 建議新增：`story_codex`（旅途手札）

- 條件：`GameState` 旗幟（如 `boss.leo_cleared`）  
- 解鎖一條：標題 + 短文（遊戲內）+ 連結「完整章」（可選）  
- UI：暫停選單／城鎮書架「翠嶺手札」  
- 資料：`game/data/story/codex_c1.json` 等  

與現有 `chapter.json` 對白**並存**：對白負責當下；手札負責餘韻。

### 3.3 小說原文存放

```
docs/story/novel/
  00_outline.md          # 總大綱 + 場景卡索引
  book1_c0_ember.md
  book2_c1_knight.md
  ...
  codex_excerpts/        # 已審核可進遊戲的短文
```

遊戲只吃 `codex_excerpts` 與對白；**全文**可同步官網「故事」頁或 itch 附贈。

## 4. Short：隨進度推進的「共進日曆」

### 4.1 兩種進度（不要混）

| 進度 | 定義 | Short 怎麼跟 |
|------|------|----------------|
| **個人進度** | 每個玩家存檔不同 | **不要**做「你打到哪就看哪」的強制鎖（難、易劇透） |
| **社群／世界進度** | 官方連載進度（週曆） | Short **跟官方進度**走 → 全頻道同一節奏 |

陪同感來自：**「這週全世界都在過騎士域」**，  
不是：「我沒打完雷歐不能看片」（那會流失潛在玩家）。

### 4.2 劇透規則（必守）

| 可發 | 暫緩／標雷 |
|------|------------|
| 氣氛、主題、角色關係 | 大反轉、魔王真身 |
| Boss **登場**與戰鬥感 | Boss **弱點完整教學**（可通關後再發） |
| 養成／世界觀 | 結局、角色死亡（若有） |

Short 文案固定加：`#本週進度 C1` 或 `通關後可安心看`

### 4.3 與 12 週表對齊（第一季）

| 週 | Short（已規劃） | 小說／手札應對 |
|----|-----------------|----------------|
| W1 | 最強？不。 | 序章開頭選段 |
| W2 | 雙武器 | 旅人擇刃的一幕 |
| W3 | 第一戰 | C0 荒路戰 |
| W4 | 器魂招 | 釘釘／星讀初遇 |
| W5 | 雷歐格擋 | C1 高潮前奏（不劇透勝敗細節可發「那一擊」） |
| W6 | 多段技 | 體悟招式的一段內心 |
| W7 | 六域 | 地圖詩意選段 |
| W8 | 防具紙娃娃 | 某職裝甲的象徵段 |
| W9 | 鍛造不掉階 | 釘釘金句小說化 |
| W10 | 開發日誌 | 可穿插「作者／世界更新」 |
| W11 | 你是哪一職 | 六職側寫各 1 段輪播 |
| W12 | 總集 | 第一部精華蒙太奇 |

第二季起：Short 題目**直接等於場景卡 ID**（例：`C2-S12 白霧的第三個影子`）。

### 4.4 「玩家進度」若仍想做個人化

進階（有 dev 成本，可後期）：

- 通關某章 → 遊戲內解鎖「本週對應 Short 連結」或「手札 + 影片」  
- 社群仍公開發，但**遊戲內標記「你已到達」** → 陪同感在遊戲裡完成  

優先順序：**先做手札解鎖，再做個人化影片入口**。

## 5. 翻拍 Short 的流水線（小說 → 片）

```
場景卡定稿
  → 抽 3 句字幕（鉤子／衝突／餘韻）
  → 對畫面：實機 or keyart or Veo（錨定該場景 mood）
  → 套 30 秒模板（見 SHORTS_12_WEEK.md）
  → 簡介：章節標籤 + 官網 +「遊戲內可解鎖完整手札」
```

**一場景卡最多生 1 支 Short**，避免同一章洗版。

---

## 6. 風險與對策

| 風險 | 對策 |
|------|------|
| 寫太久沒上線內容 | 卷級交付，不追求一次 10 萬 |
| 小說與遊戲結局衝突 | `STORY_BIBLE` 為準；小說是擴寫不是改結局 |
| Short 劇透劝退 | 分「主線安全／通關後」兩標籤 |
| 遊戲變成讀書 | 主線對白保持短；長文只在手札／官網 |
| 產能爆掉 | 每週：800 字場景 or 1 手札 + 1 Short，二選一主攻 |

---

## 7. 建議執行順序（90 天）

| 週 | 產出 |
|----|------|
| 1～2 | 總大綱 3000 字 + 場景卡表（全主線 60 卡標題即可） |
| 3～6 | **寫完並定稿 C0～C1 小說**（約 2.5～3.5 萬） |
| 同步 | C0～C1 手札 6～10 條進遊戲（可先 markdown → 再 json） |
| 每週 | 1 Short 對齊 12 週表 |
| 7～12 | C2 小說 + 手札；檢討陪同數據（觀看／官網／解鎖率） |

10 萬字目標：**約 4～6 個月**在「可維持開發」前提下合理；衝字數可更快，但遊戲同步會掉隊。

## 9. 你可以怎麼開始（最小一步）

1. 開 `docs/story/novel/00_outline.md`：六部標題 + 每部 8 個場景卡標題  
2. 只寫 **C0 第一場 1500 字**（餘燼夜）  
3. 從中壓出：遊戲 4 句對白 + Short 30 秒字幕  
4. 發 W1，遊戲裡先放 1 條手札（即使 UI 簡陋）  

陪同感的第一個火花是：**「我剛在片裡看到的，遊戲裡也有那一夜」**——不必等 10 萬字寫完。
