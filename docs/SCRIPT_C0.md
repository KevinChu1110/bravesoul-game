# SCRIPT · C0 序章「微末的白」

> 用途：對白、舞台指示、flag、戰鬥插入點。  
> 格式：`角色：台詞`；`【系統】`；`（舞台）`；`→ flag`  
> 語氣：溫暖、克制、不賣萌過頭；兔子可以怕，但不油。

---

## 開場·黑屏旁白

**【旁白】**  
勇者消滅魔王——那是二十年前的事。  
人們說太平了。傭兵團仍在招人：刀口舔血，飯碗穩一點。

**【旁白】**  
你不是勇者。你是團裡最弱的新人。  
今夜，天上又裂開紫色的縫——黑焰落下。  
上面只說：去翠谷村「看一眼」。

→ 淡入 C0-S1

---

## C0-S1 翠谷村·夜

（舞台：木屋與麥田輪廓被橙紅照亮；黑煙；遠方有不自然的暗紫邊焰＝黑焰餘燼。）

### 強制事件：麥穗

**麥穗**：（咳）別愣著——！往東，往堡壘的方向跑！

**主角**：（……）

**選項 A**「你呢？」  
**選項 B**「我去提水——」  
**選項 C**（沉默，上前扶她）

| 選項 | 反應 | flag |
|------|------|------|
| A | 麥穗：我隨後就來。別回頭。 | `c0_care = true` |
| B | 麥穗：水救不了這個。走！ | `c0_stubborn = true` |
| C | 麥穗：……傻瓜。先活著。 | `c0_care = true` |

**麥穗**：黑焰不是火。你越想「變強去砍它」，它越笑。  
**麥穗**：所以跑。跑到有石牆的地方。

（舞台：屋樑倒塌阻擋；通往村心的路斷。）

**【系統】** 只能往東逃。

### 調查：地面的劍 · **M1 拔劍三振**（爆點必做）

（若玩家靠近反光物——半截劍埋在灰裡，比兔子還長一截。）

**【系統】** 一柄鏽劍。太沉了。

（操作：互動鍵拔劍。允許跳過長演出的設定可「長按跳過」，預設播完。）

| 次 | 演出 | 音效建議 |
|----|------|----------|
| 1 | 雙手拔；劍紋絲不動；兔往後仰坐倒 | 悶金屬 |
| 2 | 咬牙再拔；劍動一寸；兔整隻被拽得前傾 | 摩擦 |
| 3 | 奮力一扯；**劍離土的瞬間兔微微離地**再砸回地面；灰揚起 | 鈍響＋短靜音 |

（落地後：劍斜靠肩，刃尖拖在地上拉出一道痕。）

**【系統】** 撿起了鏽劍。幾乎握不穩。

**主角內心**：（獨白框）總得有人……站一下。

（可選：若此時麥穗仍在視野邊緣）  
**麥穗**：（喊）別耍英雄——你連劍都……算了，帶著走！

→ `item.rusty_sword = true`  
→ `flag.c0_sword_triple_pull = true`  
→ 裝備：鏽劍 T1（攻極低）  
→ 教學提示：這就是你的武器。以後鐵匠會幫你重鍛。  
→ **成就鉤**：全程可截圖；預告片素材 H1 強化版

### 離開村子 · 麥穗的麥（N4 伏筆物）

（觸發東口前：強制或自動）

**麥穗**：（塞進你口袋一樣乾癟的麥穗桿）拿著。不是護身符。——是回家的氣味。  
**麥穗**：（遠）記住回家的路！  
（若 `c0_care`）**麥穗**：……我會等你。

→ `item.wheat_stalk = true`  
→ `flag.c0_village_left = true`  
→ 切 C0-S2

（舞台：灰藍天亮；背後煙柱；路上有逃難轍印。）

→ 進入 C0-S3 教學戰（不可逃）

## C0-S3 教學戰「渣滓之狼」

### 戰前

（一隻被黑焰沾染的瘦狼，眼有紫焰。）

**【系統·教學 1】** 戰鬥會自動進行。點敵人可鎖定目標。  
**【系統·教學 2】** 受傷會累積怒氣；滿了會使出技能——你還沒學會華麗的招，先用「橫斬」。

→ 開戰：1v1，狼血低、攻低。

### 戰中（第一次怒氣滿）

**【系統】** 怒氣滿！自動使出【橫斬】。  
（若尚未習得，戰中「身體記憶」臨時給 Lv1 橫斬 → 戰後保留）

### 戰中 · **N4 麥穗桿擋致命**（每場限一次）

（當即將受到致死傷害且 `item.wheat_stalk`：）

（時間微緩；口袋裡乾麥穗桿自己亮起一點金黃——不是魔法特效堆滿屏，一閃即可。）

**【系統】** 麥穗給的麥稈碎裂了。你撐過了這一擊。  
（HP 保留 1 或回復少量；桿從物品欄移除或變「碎麥稈」紀念物）

**主角內心**：……還在啊。氣味。

→ `flag.c0_wheat_saved = true`  
→ `item.wheat_stalk = false`（或 `item.wheat_stalk_broken = true`）

### 勝利後

**【旁白】** 狼倒下時，紫焰散成灰。它看起來……比想像中瘦。

**主角內心**：這就是黑焰嗎。連野獸都……

→ 經驗、破布、金幣少許  
→ `flag.c0_first_battle = true`  
→ 技能：橫斬 Lv1（若未有）

### 若敗北（未觸發麥稈 or 已碎仍死）

**【系統】** 醒來時在路旁。有人用斗篷蓋過你——已不見人影。  
（殘血、物品保留；狼弱化 20% 可再戰）  
→ `flag.c0_helped_by_stranger = true`（星讀伏筆）

## C0-S4 望見堡壘

（舞台：遠景石牆與旗；晨光。）

**主角內心**：石牆。煙到不了的地方。  
**主角內心**：麥穗說，黑焰吃野心。  
**主角內心**：那我……只想讓他們還在。這樣，夠不夠？

（若有鏽劍）劍穗撞腿，發出乾澀的響。

**【系統】** 主線更新：進入騎士堡壘，尋求援助與真相。

→ 淡出  
→ `flag.chapter = "C1"`  
→ 進入 C1 城門
