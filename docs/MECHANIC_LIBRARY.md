# 互動式 Boss 機制庫（從 Artale 組隊任務盤點）

> **用途**：未來新 Boss／活動／組隊挑戰的設計工具箱。  
> **來源**：`artale-lottery-bot/raid.js`、`adv-raid.js`、`adventure.js`、`quest.js`（皮卡啾關卡）、`prd.js`（組隊入口）。  
> **原則**：學的是「玩法差異與互動張力」，**不是** Discord 按鈕 UI。  
> **呈現**：翠嶺遊戲改 **2D 即時戰鬥** 時，全部改寫成場上操作（移動／時機鍵／鎖定／站位）。

---

## 0. 總原則（給未來所有新 Boss）

| 要 | 不要 |
|----|------|
| 每位 Boss **至少 1 個簽名互動** | 全 Boss 同一套普攻血條 |
| 成功改戰鬥狀態、失敗有代價 | 純文字對話「破防」 |
| 可讀預告 + 反應窗 | 無預告秒殺 |
| 機制可組合、可排程（血量％／回合） | 只能按鈕點一下結束 |
| 2D 上用站位／時機／目標表達 | 複製 Discord 選單 |

**prd 路線**：`prd.js` 的 `/突襲`、女神試煉、護送邪摩斯、野王等＝**組隊內容管線**；機制先在本庫定義，之後可出「活動 Boss」不綁主線。

## 1. 機制類型總表（抽象層）

從 raid 技能 `effect` 與排程欄位抽出，歸成 **12 大類**：

### A. 時機反應（Telegraph → Window）

| ID | 名稱 | 本質 | Artale 例子 | 2D 轉譯 |
|----|------|------|-------------|---------|
| A1 | 時機閃避 | 預告後窗內「躲」 | 火柱、落石、嘴炮、黑水、寒流、振翅 | 紅圈出現 → 移動出圈或按閃避 |
| A2 | 時機格擋／拆招 | 預告後窗內「擋」 | 王者斬類、重拳 | 前搖 pose → 格擋鍵 → 反擊 |
| A3 | 剛好 N 次反應 | 成功條件是人數／次數精準 | **避雷針**剛好 2 人 | 單人改：節奏連點 N 次／兩段時機 |
| A4 | 安全區 | 危險全域，只有區內安全 | 拉圖斯 safe_zone、長老旋風 | 地面亮安全格 → 走進去 |
| A5 | 炸彈／拆彈 | 限時處理或丟開 | bomb、金錢炸彈 | 靠近互動拆彈 or 踢開 |

### B. 目標／部位（Targeting）

| ID | 名稱 | 本質 | Artale 例子 | 2D 轉譯 |
|----|------|------|-------------|---------|
| B1 | 多部位獨立血條 | 集火選擇 | 殘暴炎魔八臂、龍王部位、皮卡啾石像 | 可鎖部位；UI 顯示多血條 |
| B2 | 必先部位 | 錯序無效／懲罰 | 混沌龍 **尾巴 mustFirst** | 先打錯部位傷害極低或反傷 |
| B3 | 真假目標 | 假的無效或反噬 | 翠嶺白霧幻影 | 鎖錯目標反噬 |
| B4 | 看破窗 | 僅特定幀可傷本體 | 翠嶺白霧發白 | 本體發光幀可傷 |
| B5 | 分頭／分階段本體 | 清完 A 才進 B | 雙頭→本體、石像→女神→皮卡啾 | 場景切換或部位全滅 |

### C. 架勢／護盾／免疫（Gate）

| ID | 名稱 | 本質 | Artale 例子 | 2D 轉譯 |
|----|------|------|-------------|---------|
| C1 | 架勢破防條 | 攻擊灌條再開輸出窗 | 翠嶺阿波 | 破防條 UI + 破防後易傷 |
| C2 | 高血護盾 | 50% 以上幾乎無敵 | 傲慢詞綴 shield | 先破盾或等階段 |
| C3 | 物理／魔法無效 | 職業互補 | 海怒斯雙無效 | 元素／武器類型切換 |
| C4 | 反射 | 打錯類型反傷 | 物理／魔法反射 | 提示後換輸出類型 |
| C5 | 縮頭免疫 | 短時間無敵 | 拉圖斯縮頭 | 停手或用法術穿透 |

### D. 層數與狀態（Stacks）

| ID | 名稱 | 本質 | Artale 例子 | 2D 轉譯 |
|----|------|------|-------------|---------|
| D1 | 火層／灼燒 | 疊高即死或重傷 | 火圈、火柱火層 | 身上層數 UI；進水／冰清層 |
| D2 | 冰／寒意 | 減速 ATB 或清火 | 火或冰圈輪替、寒流 | 移動變慢／出手變慢 |
| D3 | 腐蝕 | 輸出或防禦衰減 | 武器／防具腐蝕 | 攻擊力／受傷 debuff |
| D4 | 中毒／致盲 | DoT 或命中崩 | 毒氣、黑暗吐息 | 跳字 + 狀態列 |
| D5 | 成功疊 buff | 互動成功加輸出 | casual ⚡ 層、導雷成功 | 攻速／攻擊 buff |

### E. 召喚與時限（Adds）

| ID | 名稱 | 本質 | Artale 例子 | 2D 轉譯 |
|----|------|------|-------------|---------|
| E1 | 召喚小怪 | 不清則干擾 | 混沌小怪、黑道小弟 | 場上 add，搶鎖定 |
| E2 | 時限懲罰召喚 | 限回合內清完 | **海膽** 2 回合未清全隊 % 血 | 倒數；剩餘 add 結算懲罰 |
| E3 | 重招召喚部位 | 不清打不到本體 | 重新召喚手臂 | 手臂復活擋本體 |
| E4 | 樹妖／雜兵波 | 波次清 mob | 克雷賽爾右眼 | 波次 UI |

### F. 資源／傳遞（Team puzzle，組隊向）

### G. 風險交換（Gamble）

| ID | 名稱 | 本質 | Artale 例子 | 2D 轉譯 |

## 2. 組隊 Boss 一覽（raid.js）與簽名機制

### 2.1 拉圖斯（papulatus / hard / hell）

| 難度重點 | 簽名機制 |
|----------|----------|
| 普通 | 時鐘兩階段；物理／魔法反射；縮頭；吸血歸 1 |
| 困難 | **排程炸彈、安全區、控時、召喚** |
| 地獄 | 更密的炸彈／安全區／閃避／暈眩 |

**2D 設計鉤**：時鐘面＋安全格＋炸彈＝場地解謎型王。

### 2.2 殘暴炎魔（zakum / chaos / hell）

| 階段 | 簽名機制 |
|------|----------|
| 八臂 | **8 部位獨立血**；各手不同技能（衝擊暈、黑暗致盲、腐蝕、火藍環 dodge、落石、冰、雷） |
| 本體 | 火柱 dodge、黑水、魔方清狀態、召喚手臂擋本體、火／冰圈輪 |

**2D 設計鉤**：多部位選擇＋各部位特殊反應窗。

### 2.3 暗黑龍王（darkdragon / chaos / hell）

| 階段 | 簽名機制 |
|------|----------|
| 左右頭 | 分頭打；誘惑、寒流 dodge、疊加閃電 |
| 本體部位 | **尾巴必先**、祭壇序列、翅膀蹲、鎖鏈 dodge、狂暴頭 |

**2D 設計鉤**：順序部位＋迷你 QT 祭壇。

### 2.4 海怒斯（hainurs 系列）

| 機制 | 說明 |
|------|------|
| 嘴炮 | 血量％排程 **全員閃避**；漏按固定傷 |
| 海膽 | 召喚多隻；**物理傷海膽 -90%**；限回合未清 **每隻懲罰 % 血** |
| 雙無效 | 物理／魔法輪流無效（職業互補） |

**2D 設計鉤**：清 adds 時限＋免疫切換（元素／武器）。

### 2.5 皮卡啾（pinkbean）

| 階段 | 簽名機制 |
|------|----------|
| 石像群 | 多石像；鳥雕反盾；落石 dodge；誘惑 |
| 女神像 | 聖光柱排程、落石 |
| 本體 | 粉紅旋風蹲下、爆裂花瓣 dodge、召喚、誘惑 |

**2D 設計鉤**：三幕結構＋姿勢／閃避交替。

### 2.6 克雷賽爾（krexel）

| 機制 | 說明 |
|------|------|
| 雙眼 | 雙部位輪流出手；藤蔓掙脫 dodge |
| 回血 | 每回合微量 regen |
| 召喚樹妖 | 波次 add |

**2D 設計鉤**：雙焦點＋再生壓力。

### 2.7 黑道長老（dark_elder）

| 階段 | 簽名機制 |
|------|----------|
| 大姐頭 | 致命巴掌 dodge、河東獅吼（同步喊停）、毒氣、援兵召喚（非法師傷小怪 -90%） |
| 長老 | **信物傳遞達標才降減傷**、旋風安全區、金錢炸彈、保險櫃／顧問／飛彈 |

**2D 設計鉤**：傳遞／安全區／多物件的「資源管理王」。

### 2.8 其他

## 3. 皮卡啾關卡（quest.js Capoo）— 非血條王

皮卡啾任務關是 **多小遊戲串關**（stageOrder 隨機 3 關），重點在「關卡機制」而非單一 DPS：

| 關卡型 | 玩法本質 | 2D 轉譯方向 |
|--------|----------|-------------|
| 記憶／線索 | 收集線索再解答 | 場景調查＋拼圖 |
| 操作／限時 | 限時按鈕或移動 | 2D 小遊戲場景 |
| 投票／協作 | 組隊共識 | 組隊投票或分工 |

→ 未來「活動小遊戲 Boss」可直接用 **關卡串** 而不是長血條。
