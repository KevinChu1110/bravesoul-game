## C1-S1 城門 · 灰鬚

（舞台：高門、守城槍、逃難者被擋在外。玩家靠近。）

**灰鬚**：停。兔子？  
**灰鬚**：這裡不是菜園。回去。

**選項 A**「村子被燒了。」  
**選項 B**「我來找能打黑焰的人。」  
**選項 C**「……讓我進去就好。」

**灰鬚**：（聽完 A 或 B，沉默）……名？  
**主角**：（可輸入顯示名，預設「小白」）  
**灰鬚**：聽著，小東西。牆內也不是天堂。聖獅狂了，騎士團散了。  
**灰鬚**：你要進，就用這雙腳。別指望有人抱你。

（打開側門）

**灰鬚**：進了就別給我添亂。——還有，劍那樣握會斷手。過來。

### 迷你教學：握劍（技能）

**【系統】** 灰鬚指點了你。  
→ 橫斬確定 Lv1；若已有則 **熟練＋一大截** 或直接嘗試升 Lv2 進度  
**灰鬚**：橫著掃，別跟啄木鳥一樣戳。去吧。

→ `flag.c1_entered_city = true`

## C1-S3 鐵匠鋪 · 釘釘（裝備軸教學）

**釘釘**：門開著不是讓兔子觀光的。  
（見鏽劍）……這什麼垃圾。挖土的？  
**主角**：村子……  
**釘釘**：（奪過劍，哼）鏽進骨子了。你要走遠路，就別拿骨灰盒當武器。

**【系統】** 釘釘提出重鍛。需要：鐵屑×3、金幣×50（荒野可掉／灰鬚給起步包）。

### 重鍛完成演出 · **N2 釘釘認劍**（爆點必做）

（錘擊一：火花，鏽屑迸開。）  
（錘擊二：更沉；鏡頭可短推近刃上淺淺古紋。）

（**停錘約 2 秒。** 工坊只剩風箱餘息。釘釘盯著紋路，嘴張開又闔上。）

**釘釘**：……你從哪撿的。  
**主角**：（可選）村子／地上／不知道  
**釘釘**：（打斷）算了。  
（再錘第三下，比前兩下更輕、更準，像在對什麼道歉。）

**釘釘**：名字？……算了。叫它「微末之刃」正好。  
**釘釘**：（把劍塞回你；眼神飄開）別弄丟。  
**釘釘**：以後帶碎片回來。我幫你**升器階**。失敗不掉階——我手藝沒那麼丟人。  
**釘釘**：記好：我養的是**器**。星什麼魂什麼，去找愛看天的那個。

→ 鏽劍替換為 **微末之刃 T2**  
→ 解鎖工坊 UI：升階  
→ `flag.c1_forged = true`  
→ `flag.c1_ding_recognized_sword = true`（塔中反轉回收）

## C1-S4 星讀 · 戰魂軸教學（可在廣場夜／側殿）

**星讀**：你身上有煙味，和一點……尚未點名的星光。  
**星讀**：我是星讀。看路的人。也看「與你交疊的足迹」。  
**星讀**：（若連線 off）此刻只有你我。也很好。  
**星讀**：（若連線 on）遠方有旅人與你同看一顆星。不必相識。

**星讀**：翠嶺古法：器可養，魂可凝。  
**星讀**：路上會撿到**星屑**。拿來，我們**觀星**——不是賭博，是讓足迹凝成刃的性格。

### 強制第一次觀星（教學，主線送星屑）

（演出：星盤／葫蘆點亮 → 一枚低階戰魂；色可偏騎士金）

**星讀**：嵌進武器的空槽。它不替你變英雄；只讓刃記住一種性格。  
**星讀**：與鐵匠的錘，是兩件事。——他大概又在罵我。

→ 教學：入魂  
→ `flag.c1_soul_intro = true`

## C1-S8 雷歐戰

### 開場 · **M2 體型對照**（爆點必做）

（進戰前全屏或半屏一幀，可按確認跳過，建議預設停 1.2s：）

```
  [ 體型對照 ]
     🐰        🦁████
    你        聖獅·雷歐
```

（像素剪影即可，不必精美立繪。）

**雷歐**：渺小的兔子……也想挑戰騎士之王？  
**雷歐**：讓我看看，你配不配站在這座堡壘。

**【系統】** BOSS 戰：可鎖定部位（盔／甲／本體）。破甲會降低其防禦；破盔使其更兇，但掉落殘片。

### 階段台詞

| 血量 | 台詞／行為 |
|------|------------|
| 100% | 一般攻擊；教學鎖敵、部位 |
| 60% | **雷歐**：「只有強者……才有資格守護！」→ **王者斬**（閃紅＋長前搖；可格擋） |
| 首次王者斬前 | 【系統】爪將落下時格擋——時機正確可「以劍抵爪」！ |
| **完美格擋 · C3** | 慢鏡抵爪 → 技名橫幅 **「微末一格」** → 反擊窗；雷歐：（錯愕）……劍？ |
| 25% | **雷歐**：「為何……不退？」→ 再放王者斬；攻速↑ |
| 0% | 見清醒 |

**微末一格（規則摘要）**  
- 僅完美時機觸發橫幅（普通格擋減傷無橫幅）。  
- 音效：短促「叮」＋慢鏡環境音壓低。  
- 成就「以劍抵爪」：本戰至少 1 次完美。

### 玩家怒氣大招（若已學怒雷或用強化橫斬）

**雷歐**：（擋下）有點……像騎士。

### 敗北

**雷歐**：回去握草根吧。  
**【系統】** 回城；釘釘：劍捲刃了，我幫你修（免費一次）；可再挑戰。

### 勝利·清醒

（獅跪一膝；紫焰從瞳散去；金色清明。）

**雷歐**：原來……真正的騎士，是即使渺小也不退縮的勇氣。  
**雷歐**：（以爪扶起你的劍，鍍一層不褪金光）去吧，兔子——堡壘的門，為你而開。  
**雷歐**：其餘支柱……也在痛。記得：黑焰要的不是你的命，是你的**欲望**。別餵它。

→ `boss.leo_cleared = true`  
→ 解鎖外觀 **金鬃**（可稍後在梳毛鏡啟用）  
→ 掉落：獅之殘片、大量經驗、金幣  
→ 微末之刃可視為「被認可」染色（可選）
