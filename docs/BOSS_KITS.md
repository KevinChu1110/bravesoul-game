# Boss 互動機制設計原則

> 靈感來源：artale raid（皮卡啾／海怒斯／長老／拉圖斯等）的「每位 Boss 玩法不同」。  
> **不是**搬 Discord 按鈕；**是**把「互動式挑戰」做成即時戰鬥內操作。  
> **完整機制庫（Artale 全盤＋模板）→ [MECHANIC_LIBRARY.md](MECHANIC_LIBRARY.md)**

## 原則

1. **每位 Boss 至少一個「簽名機制」**：玩家必須用操作／判斷參與，不能純看戲。  
2. **機制改變戰鬥狀態**：成功＝輸出窗／增益；失敗＝扣血／減速／疊傷——不是純劇情。  
3. **禁止**：只靠文字選項破防、只靠一個無腦按鈕秒破、全 Boss 同一套。  
4. **允許**：格擋、鎖定目標、破防條、閃避窗、部位優先、層數風險、安全區等。  
5. **敘事選擇**（如魔王「我拒絕」）可保留，但**不能是唯一機制**，旁邊要有戰鬥互動。

## 機制類型（工具箱，按 Boss 組合）

| 類型 | 玩家在做什麼 | artale 對照 |
|------|----------------|-------------|
| 時機格擋／反擊 | 前搖可讀 → 窗內按鍵 | 王者斬、部分 dodge |
| 時機閃避 | 危險預告 → 窗內閃 | 火柱／落石／嘴炮 |
| 多目標鎖定 | 選真假／部位 | 石像群、雙頭、幻影 |
| 看破窗 | 僅特定時段可傷本體 | 霧、某些破盾 |
| 架勢破防條 | 攻擊灌條再重創 | 高防階段 |
| 必先部位 | 錯序無效或懲罰 | 暗黑龍尾 |
| 風險層數 | 成功疊 buff／失敗疊 debuff | 避雷針剛好 N 人 |
| 安全區／炸彈 | 時機進區或拆彈 | 拉圖斯時空 |
| 召喚物 | 先清小怪否則干擾 | 召喚波 |

## 翠嶺各 Boss 套件（定稿）

| Boss | 簽名機制 | 副機制 | 玩家操作 |
|------|----------|--------|----------|
| **雷歐** | 王者斬 **格擋反擊** | **火圈** 週期閃避窗 | J 格擋／J 閃火圈 |
| **白霧** | **多目標**＋**看破窗**才傷本體 | 打幻影反噬；幻影攻擊附 **寒意**（ATB 變慢） | Tab/1/2/3 鎖；看破時輸出 |
| **阿波** | **架勢破防條**（攻擊灌） | 破防後 **重拳前搖** 可格擋 | 普攻/技能灌條；破防中 J |
| **魔王** | 黑焰必殺格擋＋**三拒**（敘事削弱） | **控時時鐘**：週期出現，準點按＝我方加速／Boss 減速，漏按＝我方 ATB 凍結 | J 必殺；時鐘窗按 J；拒選項 |
| **疾影**（C4） | **停拍／殘影**：僅真身定格窗全額傷害 | **風切** 直線危險區閃避 | 等停再打；J 或橫移閃風 |
| **石拳**（C5） | **對撞破岩甲**（衝鋒窗 J 卸力剝甲） | **落岩安全區** | 對撞剝甲；進安全區 |
