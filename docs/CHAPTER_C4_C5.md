## C4 · 遊俠森林「風之試煉」

### 主題一句

> 追風會迷路；等風，風才肯停。

### 場景節點（2D 可走）

```
[樹屋聚落]——[箭道]——[觀風塔]
     |              |
 [藥草坡]      [疾影巢·Boss]
```

| 節點 | 內容 |
|------|------|
| 樹屋 | NPC **風耳**（P1）；接「等風」教學小任務 |
| 箭道 | 小怪波次；地上偶發 **風切** 危險區（預熱 A1） |
| 觀風塔 | 調查：疾影過去守護的碑文 |
| 藥草坡 | 材料／支線 |
| Boss | 疾影巢 |

### NPC

| ID | 名 | 作用 |
|----|-----|------|
| N11 | **風耳** | 弓系導師語氣；教「等一下再射」；疾影後改台詞 |
| — | 樹屋孩童×1 | 輕支線：找回被風吹走的風箏 |

### Boss · 疾影（簽名互異）

| 層 | 機制 | 庫 ID | 玩家操作 |
|----|------|-------|----------|
| **簽名** | **殘影換位**：場上 1 真身 + 2 風殘影快速輪轉；**只有真身停頓的短窗**可造成全額傷害 | B3+B4 | 看哪個停下來鎖／打 |
| **副** | **風切直線**：預告地面風道 → 窗內閃避（J 或橫移出線） | A1 | 預告後閃 |
| **禁止** | 對話破防、純選項 | — | — |

**節奏：**  
- 多數時間疾影「模糊」— 實傷 chip only  
- 每 3～4 秒 **停拍 0.9s**（真身定格、邊緣亮）→ 全額傷害窗  
- 同時每 10s 一道風切需閃  
- 血量 40% 後：殘影加速、停拍略短；風切變雙線（先後）

**失敗代價：**  
- 打殘影：落空 + 小硬直  
- 漏閃風切：% 最大生命傷害 + 短暫 ATB 慢（被風帶走）

**勝利文案方向：**  
「你追上了風……有趣的傢伙。」→ 疾風外觀契機。

### 養成掛鉤

- 弓／遊俠碎片掉落（若尚未開弓線：只掉通用礦＋金幣亦可）  
- 風耳可教 **速射** 技能一階（6m）

| flag | 含義 |
|------|------|
| `c4_entered` | 進過森林 |
| `boss.shadowwind_cleared` | 疾影勝 |
| `cosmetic.gale_fur` | 疾風外觀 |

## C5 · 維京海岸「岸上最後一擊」

### 主題一句

> 力氣若沒有方向，只是浪打空岸。

### 場景節點

```
[碼頭鎮]——[峭壁道]——[祭壇]
    |           |
 [鍛爐]    [石拳崖·Boss]
```

| 節點 | 內容 |
|------|------|
| 碼頭 | NPC **潮吼**；比腕力小遊戲可選（非破防） |
| 鍛爐 | 升階材料；潮吼送斧意一句 |
| 峭壁 | 小怪；地面 **落岩預告**（A1 預熱） |
| Boss | 石拳崖 |

### NPC

| ID | 名 | 作用 |
|----|-----|------|
| N12 | **潮吼** | 莽、豪；戰前激將；石拳後大笑認你 |

### Boss · 石拳（簽名互異）

| 層 | 機制 | 庫 ID | 玩家操作 |
|----|------|-------|----------|
| **簽名** | **對撞蓄力**：Boss 衝鋒前有長前搖；玩家在窗內按 **對撞（J）** 可卸力並反震破「岩甲層」 | A2 變體 | 時機對撞，不是問答 |
| **副** | **落岩安全區**：砸地後全場危險，僅亮區安全 → 需進區（2D 移動）或暫以「安全提示+J 蹲」占位 | A4 | 進安全區／蹲 |
| **岩甲** | 有 2～3 層岩甲時實傷大減；**對撞成功剝一層**；剝光才好殺 | C1 變體 | 多次對撞 |

**節奏：**  
1. 石拳蓄力衝鋒（1.4s 前搖，可讀）  
2. 窗 0.8s：J＝對撞成功（慢鏡、岩甲 -1、反傷一段）  
3. 失敗＝高額衝撞傷  
4. 每剝一層甲後放落岩：安全區 1.0s 預告 + 0.7s 必須進區  
5. 無甲時石拳變快但可打；30% 血再長一層甲（最後一次）

**失敗代價：** 衝撞傷、落岩 % 血  
**成功回報：** 破甲、短易傷

**勝利文案：**  
「哈哈哈！站到最後的是你！」→ 炎心外觀。

## 與 C6 的銜接

- **五柱全清**（雷歐+白霧+阿波+疾影+石拳）：塔下斷頁台詞加一句「五柱都鬆了……門開得更亮。」  
- 僅三柱（現最短）：仍可進塔（現況），斷頁說「有人抄近路……塔不等齊。」  
- 不強制 C4/C5 才能通關，但 **完美結局色／稱號** 可綁五柱（6m）。
