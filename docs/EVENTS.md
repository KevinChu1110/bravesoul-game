## 玩家入口

| 入口 | 說明 |
|------|------|
| 標題「活動·… ★」 | 當月活動 |
| Esc 同名 | 旅途中 |
| 世界輿圖 | 有活動時 |
| **歲旅石** | 岔路／行商驛／疤地 |
| 行商 | 活動期對話後進面板 |

## 當月玩法

1. **有獎挑戰**（每日 3）→ 活動幣 + 金  
2. **任務**（初試／三日／十日／秘境專屬）→ 一鍵領  
3. **商店** 用活動幣換消耗品  
4. **今日三件事** 登入 + 活動 + 探索 → 小獎勵  
5. **過月收攤** 剩幣 × rate → 金

## 加新活動

1. 複製任一 JSON  
2. 改 `id` / `name` / `recurring_month` / 商店任務  
3. 放進 `game/data/events/`  

Schema：`game/data/events/schema.md`
