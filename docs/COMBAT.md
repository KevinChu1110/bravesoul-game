# COMBAT · 即時戰鬥完整規格

> 目標手感：原版頁遊雜魚戰的**當場互毆**；BOSS 有策略與台詞。  
> 禁止主路徑使用「整場結算再播 log」（舊 Discord 模型）。

---

## 1. 體驗定義

| 模式 | 體驗 | 玩家在做什麼 |
|------|------|----------------|
| 野外雜魚 | 即時自動 | 看戲為主；可鎖敵、開技優先、用道具、逃 |
| 精英 | 即時＋機制 | 可讀前搖；可選輕時機（6m） |
| 聖獸 BOSS | 即時為底＋**高光層**＋策略層 | 部位、階段、**可反制必殺** |
| 教學戰 | 降速＋提示 | 鎖敵、怒氣；**不**在第一戰逼格擋 |

**成功標準：**  
1. 錄 10 秒無 UI 也能看出「誰在砍誰」。  
2. 雷歐戰至少 1 次可剪成 5 秒 clip 的慢鏡高光（見 §6.5）。

### 1.1 高光層原則（2026-08 定案）

- **不**把整作改成動作遊戲；雜魚維持放置感。  
- **BOSS 必殺**必須可讀、可反制、成功有**慢鏡＋反擊窗**。  
- 失敗可硬扛通關（故事模式）；完美反制綁成就與秀。  
- 評析：[DESIGN_CRITIQUE.md](DESIGN_CRITIQUE.md)

## 2. 戰場佈局

```
  [敵3] [敵2] [敵1]        ← 敵方站位（最多 5，3m 先 3）
        ↘  ↙
         碰撞／彈道區
        ↗  ↖
       [兔勇者]            ← 我方（3m 單人；6m 可助戰影子）
```

- 側視或 3/4 俯視像素，**站位固定槽**，攻擊時短位移再回槽（好做、好讀）。  
- 背景：域主題（堡壘石牆、霧林…）。  
- HUD：我方大血條＋怒氣；敵方頭上血條；當前鎖敵高亮。

## 3. 時間模型（BattleSim）

### 3.1 時鐘
- 固定邏輯步：`tick = 1/30 s` 或 `dt` 累積（實作可選，設計以**秒**為單位寫）。  
- 戰鬥 `time_scale`：預設 1.0；設定可 1.5／2.0（快轉）；劇情可 0.3 慢鏡。

### 3.2 單位狀態機

```
        ┌──────────────────────────────────────┐
        ▼                                      │
     Idle ──(ATB滿)──► Windup ──► Strike ──► Recover ─┘
        │                  │
        │                  └──(被硬直)──► Stagger ──► Idle
        │
        └──(怒氣滿且可放技)──► Cast ──► SkillStrike ──► Recover
```

| 狀態 | 行為 | 時長來源 |
|------|------|----------|
| Idle | 播呼吸；累積 ATB | — |
| Windup | 抬手／前衝開始；可被打斷（6m） | 武器風姿 |
| Strike | 判定幀：命中／暴擊／傷害 | 極短 |
| Recover | 後搖，ATB 重置 | 武器風姿 |
| Cast | 技能前搖，特效起手 | 技能表 |
| Stagger | 受擊硬直（可選） | 受擊強度 |

### 3.3 ATB／攻速
```
每秒 ATB += base_fill_rate * f(speed) * (1 + atb_bonus)
ATB >= 100 → 嘗試進入 Windup（對當前目標）
```
- `speed` 高 → 出手頻；與舊作「速度決定先後」同精神，但是**連續時間**。  
- 武器風格：  
  - 劍：中速中傷  
  - 匕首：快、單下低  
  - 斧：慢、單下高、variance 大  
  - 拳：快連段（技能多段）  
  - 弓／杖：中遠、前搖略長  

### 3.4 目標選擇
- 預設：鎖定最近／最前排存活敵。  
- 玩家點敵頭像或單位 → 改 lock。  
- 目標死亡 → 自動下一個。  
- 治療技：目標改為自己（3m 無隊友）。

## 4. 判定與公式（規則層）

> 與畫面分離；數值初值見 BALANCE.md。

### 4.1 命中
```
miss_chance = clamp( g(speed_diff) + EVA - HIT , 0%, 95% )
```
- 命中／迴避為可破百的百分點（延續考據）。  
- miss → 跳字「未中」、無傷害、仍耗本次 ATB 週期。

### 4.2 傷害
```
raw = atk * skill_multiplier * (1 + variance_roll)
def_reduce = f(def)
damage = max(1, raw 經防禦衰減)
```
- 暴擊：`eff_crit = max(0, crit - crit_resist)`；暴擊乘 `crit_damage`。  
- **克制無平白倍率**；克制來自裝備天生 HIT/EVA/CRIT/RESIST 差（延續設計）。  
- 戰魂加在 atk／crit／等面板，不另開無敵倍率。

### 4.3 怒氣
```
受傷時：rage += k * (dmg / max_hp) ，上限 per_hit
滿 100：可 Cast 技能（隊列中優先大招）
放完：rage = 0（或留一小截，BALANCE 定）
```
- 未學任何技能：不顯示怒氣條。  
- 技能升級可影響 `rage_cost` 或填充效率（見 PROGRESSION）。

### 4.4 死亡與勝利
- HP<=0 → Die 狀態 → 播死亡 → 移出鎖定。  
- 全敵死亡 → Victory（短慢鏡＋結算）。  
- 我方死亡 → Defeat → 回檢查點，不毀存檔進度旗標（可重試）。

## 5. 事件流（Sim → View）

Sim **只**廣播，例如：

| 事件 | 用途 |
|------|------|
| `battle_start` | 佈陣、BGM |
| `unit_spawn` | 生成 |
| `state_change` | 切動畫 |
| `attack_swing` | 揮擊音／刀光 |
| `hit` / `miss` / `crit` | 跳字、閃白、擊退像素 |
| `skill_cast` | 大特效、技能名橫幅 |
| `hp_changed` / `rage_changed` | HUD |
| `unit_died` | 倒地 |
| `part_broken` | BOSS 部位 |
| `battle_end` | 結算 UI |

View **禁止**重算傷害；若需預測（如傷害預覽）走同一 formulas 純函式。

## 6. BOSS：雷歐與通用聖獸

### 6.1 模式建議（定稿方向）
**即時底盤 + 可暫停的「指令窗」**（每 N 秒或每次我方大招後）：

1. 平時雙方即時互毆（同雜魚）。  
2. BOSS 血量跨階段 或 我方怒氣滿時，可進入 **0.2～0.5s 選擇窗**（可設定自動）。  
3. 選擇：**集火本體**／**部位 A/B/C**／**防禦姿態**（若有）。  
4. 選完恢復即時。

3 個月若做不完暫停窗：改為**戰鬥前選集火部位**，戰鬥中可切換（熱鍵），不暫停。

### 6.2 部位破壞（延續精神）
| 部位 | 破壞效果（示例） | 掉落敘事 |
|------|------------------|----------|
| 盔 | BOSS 攻↑（變兇）但掉殘片 | 驕傲的冠 |
| 甲 | BOSS 防↓ | 守護之甲裂 |
| 爪／靴 | BOSS 速↑或↓ | 視設計 |
| 本體 | 主血條 | — |

全破後本體虛弱：受傷增加。  
**只有打贏才給殘片與主線 flag。**

### 6.3 雷歐專屬（C1）——全作操作高光原型
- 三階段血量 100%／60%／25%。  
- 階段台詞見 SCRIPT_C1。  
- **王者斬（P0 必做精）：**
  1. 長前搖（約 1.0～1.2s）＋畫面邊緣閃紅／獅爪抬高可讀 posing  
  2. **時機窗**約 0.35～0.45s：玩家按下格擋／互動鍵  
  3. **完美**：進 0.6～1.0s 慢鏡「以劍抵爪」→ 雷歐硬直 → 玩家免費怒氣技或高傷反擊窗  
  4. **普通／失敗**：受高傷或強制防禦減傷（故事模式自動減傷更高）  
  5. 一場戰至少放 2 次王者斬，給練習與 clip 機會  
- 部位破壞仍保留（甲／盔）。  
- 清醒演出：跪地對話，不瞬逃。

### 6.4 其他聖獸（機制差異，見 SHARE.md）
| BOSS | 3m | 機制摘要 |
|------|-----|----------|
| 白霧 | 擇一精做 | 幻影；僅真實破綻幀可傷本體 |
| 阿波 | 擇一精做 | 高防＋戰中對話分支影響節奏 |
| 疾影／石拳 | 6m 或底模 | 停拍幀／對撞一擊 |
| 魔王 | 3m 必做敘事機制 | 下節 |

### 6.5 魔王（C6）——敘事高光
- **揭露後再戰**（先劇情反轉，再最終戰；見 STORY_BIBLE）。  
- 三階段誘惑：**力量／復仇／安穩**；每次「拒絕」削弱其黑焰外殼、改變招式表。  
- 終段外觀剝落為「舊至弱者」輪廓（可仍是獸形殘影，避免直球抄主角）。  
- 可保留 1 次「黑焰必殺」時機格擋，復用雷歐輸入，降開發量。

## 8. 波次與遭遇

- 野外節點：1～3 波，每波 1～3 敵（3m）；總長 30～90 秒。  
- 遇敵方式：進節點自動進戰 或 地上影子接觸（擇一，建議節點自動減少煩躁）。  
- 勝利：經驗、金幣、碎片、低機率粗胚。
