# 演武場／角鬥日結

> 對齊原作精神：**演武**＝挑戰狀換經驗與磨刀；**角鬥日結**＝換日依成績發獎。  
> 本體仍是 **PVE 五波天梯**（非即時 PVP）。

## 規則

| 項 | 規格 |
|----|------|
| 解鎖 | 進入騎士堡（同獵場） |
| **挑戰狀** | 上限 **5**；約 **90 分**回復 1 張（原作演武票） |
| 有獎開戰 | 消耗 1 張挑戰狀；無狀→練習 |
| 結構 | **5** 波：灰燼鼠 → 殘兵 → 霧影 → 海盜 → 焰靈 |
| 分數 | 每波 1000 + 殘血（≤200）；記個人最佳 |
| 獎勵 | 輕金＋**經驗（比野外厚）**；**不掉**獵場材料 |
| 練習 | 金×0.35、分數不上榜 |
| 排行 | 本地 PB；登入後可 `leaderboard_submit("arena_best")` |
| **角鬥日結** | 換日依「昨日最高分」：新銳≥1／精銳≥2000／菁英≥4000／至尊≥6000 → 金＋星屑＋**寶石** |

## 入口

- Esc 暫停 →「今日村莊」→「演武場」
- Esc 暫停 →「演武場」
- Esc →「寶石工坊」（日結寶石在此合成／鑲嵌）

## 實作

| 模組 | 檔案 |
|------|------|
| 邏輯 | `game/scripts/systems/arena_system.gd` |
| 挑戰狀欄位 | `GameState.arena_tickets` / `arena_ticket_ts`（存檔 v8） |
| UI／戰鬥收尾 | `main.gd` `_go_arena_panel` / `_on_arena_battle_finished` |
| 每日導流 | `QuestSystem` 委託 `d_arena` |
| 稱號 | `title.arena_challenger` |

## 非即時 PVP（好友殘影）

登入後上傳自己的戰鬥殘影；好友挑戰可打**其他旅人留下的數值**，不是即時操作。離線仍打傭兵團名冊。表：`pvp_snapshots`。

即時同場、組隊房、23:00 封板、賽季清零——仍不做。
