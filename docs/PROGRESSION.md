# PROGRESSION · 三重養成設計

> 定案（2026-08）：**裝備升階、戰魂、技能升級三軸並存**。  
> 戰魂在體感上接近「裝備的第二層強化」，但來源與風險不同；技能是「戰鬥中的表現成長」。  
> **0.12.0**：等級經驗、自由路線軟鎖。  
> **0.13.0**：**十種武器流派**（劍弓法拳斧鎚槍銃鏢晶）與器／魂／招分離；「星途觀星」= 戰魂（非職業）；舊「鐵骨守護」廢名，血防向用鎚／水晶。

---

## 1. 設計問題與解法

### 問題
若戰魂 ≈ 裝備升級、技能也要升級，容易變成**三個吃素材的同一種 +N**，玩家煩且無意義。

### 解法：三軸正交

| 軸 | 綁定對象 | 成長資源 | 失敗風險 | 可重置？ | 敘事味道 |
|----|----------|----------|----------|----------|----------|
| 裝備升階 | 單件裝備本體 | 職系碎片＋金幣 | 失敗**不掉階**、耗材仍扣；有保底 | 不可（階綁裝備） | 鐵匠、錘聲、材料烙印 |
| 戰魂 | 嵌在裝備的魂槽 | 聚魂產出／合成 | 品質看魂器運氣；可拆魂換裝 | **可拆**回背包 | 星曜、葫蘆、祭儀 |
| 技能 | 角色已學會的招 | 技能經驗／秘卷／導師 | 無失敗；有等級上限 | 不需 | 導師、體悟、招式名 |

**心智模型（給玩家的一句話）：**

> 鐵匠養**器** · 星途養**魂** · 旅途養**招**。

## 2. 裝備升階（器）

### 2.1 取得
- **不可用商店買成品武器神裝**（延續考據精神）。  
- 來源：野外掉落粗胚、BOSS 部位殘片、任務、鐵匠用碎片鍛造。  
- 槽位（3 個月）：武器、防具；（6 個月）飾品 6 槽。

### 2.2 升階規則（T1～T15）
- 消耗：該職系**碎片**＋金幣。**實作**：升階價＝ 40 × 目前階數
  （T2 是 80、T10 是 400），T2 一路練到 T11 期望約 3500 金。  
- 成功率隨階下降（**實作**：`0.80 − 0.03×(階−1)`，下限 0.45）；
  **失敗不降階**；連續失敗 3 次保底成功。  
- 每升階：主屬性↑；在 T1／T6／T11 各開 **1 個魂槽**（最多 3）。  

> **鍛造上限現在是 T11**（`main.gd` 的 `FORGE_MAX_TIER`），不是三個月切片寫的 T8。
> 那個 T8 曾經跟魂槽的 T11 門檻對不上 —— 第三個魂槽是一個玩家再怎麼玩都
> 拿不到的獎勵，而且不會報錯，只會讓人以為自己漏了什麼。
> `test_progression.gd` 現在守著「每個魂槽門檻都要在鍛造上限之內」。
- 換武器：舊武器的**階**留在舊件；戰魂可拆到新件（見下）。

### 2.3 敘事綁定
| 節點 | 事件 |
|------|------|
| C0 | 撿「鏽劍」T0／T1 占位 |
| C1 釘釘 | 重鍛為「微末之刃」——第一次正式升階教學 |
| 各域 | 對應碎片故事（騎士碎、霧隱鐵砂…） |
| BOSS | 部位殘片用於高階鍛造，不是另一套神裝系統 |

### 2.4 玩家決策
- 養一把主武深，還是多職淺（換武器換技能流派）。  
- 高階成功率 vs 保底心理。

## 3. 戰魂（魂）——「裝備的靈魂層」

### 3.1 定位（相對裝備）
| | 裝備升階 | 戰魂 |
|--|----------|------|
| 給什麼 | 全面底盤（攻防血） | **偏科**（暴擊、命中、吸血感、怒氣效率等單點） |
| 怎麼變強 | 同一件一路砸 | 抽／合成換更好的魂 |
| 運氣 | 升階成功率 | 聚魂品質＋葫蘆跳階 |
| 換裝 | 階綁裝備 | **可拆魂**，名品可帶走 |

戰魂**不是**第二條「+攻% 的升階條」，而是：

> 決定這把武器「性格」的插件；同一把 T10 劍，嵌不同星曜，打起來手感不同。

### 3.2 戰魂取得（去 gacha 化 · 2026-08 定案）

> 獨立遊戲受眾視「每日抽＋金幣抽」為紅線。興奮感應來自**探索與足跡**，不是轉蛋 UI。

| 不做 | 改做 |
|------|------|
| 每日限次抽 | 無每日牆 |
| 付費貨幣／雙幣抽 | 永不做 |
| 對外文案「抽卡／保底」 | 「觀星／凝魂／星屑」 |
| 純隨機當主取得 | **探索驅動** |

**取得流程：**

1. 野外節點、調查點、支線、BOSS 首次 → 掉落 **星屑／星曜殘片**（可標在地圖邊緣微光）。  
2. 帶到 **星讀／觀星台** 交付，舉行 **觀星儀式**（可保留葫蘆點亮演出）。  
3. 結果 **品質／星型** 主要受 **足跡權重** 影響，例如：  
   - 剛淨化騎士域 → 攻／勇相關星權重↑  
   - 關鍵選擇偏守護 → 防／梁權重↑  
   - 進度越高 → 高品質權重溫和上升（**不**鎖主線）  
4. 少量隨機保留在「同權重池內的抖動」，避免完全可預測無聊。  
5. **合成 3 合 1** 仍保留（輕養成深度，非付費 gacha）。  

**魂器色階（可選保留）：**  
觀星次數／主線里程提升「星圖亮度」階，敘事化為葫蘆／星盤階段，**不要**做成「付費跳階」。

**主線保證：**  
雷歐前星讀教學給 1 次觀星＋1 顆可用凡／吉魂；之後主線節點必給足夠星屑，**從不**逼刷才能打 BOSS。

### 3.2.1 興奮感補強（R2 · 不回 gacha）

> 用「發現儀式感」替代轉蛋刺激。

| 層 | 做法 | 3m 最低 |
|----|------|---------|
| 靠近星屑 | 兔耳動 **或** 劍微震 **或** 短「叮」 | **至少一種** |
| 拾取 | 星屑從環境「剝離」飛入（≤1s） | 可簡：縮放+音效 |
| 觀星 UI | 先依足跡**連線／高亮星區** → 再點亮具體魂 | 必做簡版（色塊即可） |
| 定向驚喜 | 在**雷歐跪地座標**觀星 → 勇／攻權重↑；持**碎麥稈** → 防／梁或特殊對話 | 權重偏移，**非 100%** |

社群話術目標：「我在獅子倒下的地方觀星出了……」≠「我今天抽到了」。

### 3.3 戰魂結構
```
戰魂 = {
  star,      // 十四主星之一：決定加什麼屬性
  quality,   // 大凶→凡→吉→大吉→稀世→神：倍率
  level,     // 0～3：合成小幅加強（同星同品 3 合 1）
}
```
- **入魂**：放進武器／防具空槽（飾品不嵌，避免爆炸複雜）。  
- **拆魂**：工坊／祭壇操作，魂回背包（可收手續費金幣）。  
- **合成**：3 同星同品同階 → 階+1（上限 3），**不改品質**，只微調強度。

### 3.4 十四星（設計用分類，數值見 BALANCE）

| 類型 | 星例 | 傾向 |
|------|------|------|
| 攻擊 | 七殺、破軍、貪狼 | 攻、暴、傷幅 |
| 防禦 | 天同、天梁 | 防、血、抗暴 |
| 技巧 | 天機、天相 | 命中、迴避、攻速 |
| 特異 | 紫微、武曲、太陽、太陰… | 怒氣、吸血感、技能增幅等（每星唯一） |

（完整十四星表實作時鎖死一版，避免與技能效果重疊過多。）

### 3.5 與裝備的「類似」如何向玩家講清楚

UI 文案建議：

- 裝備頁：「**器階** T7｜魂槽 ●●○」  
- 點魂槽：「嵌戰魂＝為這件裝備寫上星名」  
- 升級按鈕在鐵匠；聚魂在**聚魂殿／星讀祭壇**——空間分離，降低混淆。

### 3.6 敘事
- **星讀（N10）**：第一次**觀星**教學、解釋星屑與足迹。  
- 星盤／葫蘆可為「聖獸時代留下的器」。  
- 首次高品質觀星可進典籍「曾見神曜」——獎勵探索，不是課金。

## 4. 技能升級（招）

### 4.1 定位
- 技能決定**戰鬥演出與節奏**（多段、治療、破防、大招）。  
- 升級強化的是「這招本身」，不替代裝備底盤。  
- **裝什麼武器，自動只能用該武器流派技能**（延續舊作武器決定流派）。

### 4.2 習得 vs 升級（分開）

| 階段 | 怎麼來 |
|------|--------|
| **習得** | 主線／域導師任務／等級門檻解鎖「學會這招」 |
| **升級** | 戰鬥中該技能有貢獻（擊中／治療成功）累 **技能熟練**；或交秘卷／導師突破 |

### 4.3 技能等級（建議 Lv.1～5，3 個月可先 1～3）

| 等級 | 大致強化（方向） | 演出 |
|------|------------------|------|
| 1 | 學會，基礎倍率 | 基礎特效 |
| 2 | 倍率↑ 或 CD↓ 小 | 特效略大 |
| 3 | 附加小效果（短破甲／多 1 hit） | 新增層 |
| 4 | 明顯變強（6m） | 新動作幀 |
| 5 | 滿級稱號感（6m） | 專屬收招 |

**原則**：升級**優先改手感與可讀性**，不要每級只 +3% 攻到無感。

### 4.4 怒氣與釋放（即時戰鬥）
- 受傷累積怒氣；滿可放「當前武器可放的最高優先技能」（或玩家預設技能隊列）。  
- 大招（原 16 級暴怒技）怒氣門檻更高或需滿怒＋冷卻。  
- 技能升級可微降怒氣需求或縮短 recover，讓老練角色「招更快更炫」。

### 4.5 技能樹範圍（3 個月）
- 先做透 **劍／騎士** 全線（對應 C0–C1 主武器）。  
- 每再到一完整域，解鎖該域對應武器線的 1～2 招（C2 匕首、C3 拳）。  
- 其餘武器線 6 個月或通關後。

### 4.6 敘事掛點
| 技能 | 誰教／何處悟 |
|------|----------------|
| 橫斬 Lv1 | 灰鬚「這樣握，別捅到自己」 |
| 緊急恢復 | 騎士域任務／斷頁的舊卷 |
| 怒雷狂擊 | 雷歐認可後體悟 或 等級門檻＋試煉 |
| 霧系技 | 霧隱 |
| 拳系技 | 阿茶／阿波 |

## 5. 三者同時成長時的節奏（防肝）

### 5.1 主線推進時自動給夠
- 主線戰鬥掉**當前域碎片**與金幣，足夠把主武維持在「可打下一個 BOSS」的器階。  
- 技能熟練主要靠**打主線就會漲**，不要求專門刷同一招 2 小時。  
- 聚魂：每日免費 1 次＋主線送少量「聚魂石／虔誠幣」；**不卡劇情**。

### 5.2 深度給喜歡養成的人
- 刷野、拆魂重配、技能 4～5 級、T12+ 給通關後與連線裂縫。

### 5.3 建議的「戰力感覺」來源比例（目標手感，非嚴格公式）

| 來源 | 約略貢獻 |
|------|----------|
| 角色等級＋裝備器階 | 50% |
| 戰魂 | 25% |
| 技能等級與搭配 | 15% |
| 操作（鎖敵、時機道具） | 10% |

## 6. 角色等級

- 仍有效：推血攻防底盤、解鎖技能習得門檻、部分裝備穿戴。  
- 經驗：主線戰鬥、支線、首次 BOSS 大包。  
- **不**用體力卡主線（單機敘事模式體力關閉或極寬）。
