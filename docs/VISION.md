# VISION · 勇者之魂

## 一句話

一隻不慕強權的兔子，在黑焰吞噬野心的翠嶺大陸上，靠對話、選擇與即時戰鬥，喚醒聖獸、對抗魔王——並在需要時，與其他旅人短暫並肩。

## 玩家會記得什麼

- **世界**：翠嶺有氣味、有鎮民閒話、有會隨主線改變的 NPC。  
- **角色**：不是選單裡的白兔，而是「連劍都快拿不動卻仍站出來」的具體存在。  
- **戰鬥**：雜魚戰像原版頁遊那樣**當場互毆、血條在動**；BOSS 有策略與台詞。  
- **主題**：真正的力量不在體型與野心，而在不低頭的心（黑焰克星）。

## 體驗支柱（依優先）

1. **敘事與世界感** — 城鎮、道路、典籍、NPC 關係  
2. **即時戰鬥演出** — 站位、出手、受擊、技能特效  
3. **養成有情感回饋** — 裝備／戰魂綁「誰教你的、為何而戰」  
4. **輕連線** — 看見他人、共鬥可選，不破壞沉浸  

## 基調

| 面向 | 方向 |
|------|------|
| 文字 | 史詩底＋溫暖（兔視角）；Boss 有個性獨白 |
| 畫面 | 復古像素、可讀 UI、戰鬥要「好看」 |
| 節奏 | 探索／對話 與 戰鬥 交替；不逼肝 |
| 幽默 | 輕量（兔子拿巨劍等反差），不消解悲劇 |

## 目標受眾

- 喜歡輕度 JRPG／放置戰鬥、願意讀劇情的玩家  
- 可能曾接觸舊《勇者之魂》／聚魂 Online 氣氛的人  
- 可單人完整遊玩；有朋友時才開連線內容  

## 產品定位（對外一句）

> **敘事優先的像素 RPG。日常戰鬥如呼吸，聖獸戰會記得你。**  
> EN: *Most battles breathe—boss battles remember.*  
> （勿單獨標榜 Action RPG，避免類型錯位。）

## 明確不做（願景層）

- 做成 Discord bot 或依賴 Discord 才能玩  
- 做成必須組隊才能推主線的 MMO  
- 無劇情的數值競技場為主體  
- 開放世界無縫大地圖（用地圖節點／場景切換）  
- 從第一天就營運賽季課金框架
