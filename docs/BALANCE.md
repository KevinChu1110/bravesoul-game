# BALANCE · 數值起點

> 初值，實測必改。改數值盡量只動本檔對應表。  
> 精神繼承舊作：失敗不掉階、命中迴避可破百、克制無平白倍率、聚魂跳階稀有。

- 3 個月主線：**不要求**稀世才能打雷歐；凡／吉足夠。

## 4. 技能

### 劍系（3m 核心）

| key | 名 | 習得 | 倍率 Lv1 | CD 概念 | 怒氣 |
|-----|-----|------|----------|---------|------|
| slash | 橫斬 | C0/C1 | 1.8 | 短 | 標準 |
| counter_strike | 反戈一擊 | Lv7 或任務 | 2.4 | 中 | 標準 |
| emergency_heal | 緊急恢復 | C1 任務 | heal 30% | 長 | 標準 |
| thunder_fury | 怒雷狂擊 | 雷歐後或 Lv16 | 2.6 | 長 | 需滿怒優先 |

### 技能等級係數
```
final_mult = base_mult * (1 + 0.12 * (skill_lv - 1))
```
Lv3 可另加：橫斬附帶小範圍、恢復 +5% 等（見 PROGRESSION）。

### 熟練
- 有效命中技能：+1～3 熟練。  
- Lv1→2 需 30；2→3 需 80（可調）。  
- 主線正常打，雷歐前橫斬應到 Lv2。

## 5. 戰鬥時間參數

| 參數 | 初值 |
|------|------|
| ATB 滿值 | 100 |
| 基準每秒 ATB | 25 → 約 4 秒一刀（speed=10） |
| speed 影響 | `fill *= clamp(0.6 + speed*0.04, 0.5, 2.0)` |
| Windup 劍 | 0.25s |
| Recover 劍 | 0.40s |
| 怒氣 per 傷 | `40 * dmg/max_hp` 上限 40／下 |
| 暴擊傷害 | 150% 面板（crit_dmg 50% 加成算法另定） |

### miss
```
miss% = clamp(floor(sqrt(max(0, 5*(spd_def-spd_atk)))) + eva - hit, 0, 95)
```
