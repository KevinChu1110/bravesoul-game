## C6-S4 魔王戰

### 開場

（黑焰外殼覆上；體型膨脹；聲音變低。）

**魔王**：那就來——用你的微末，撞我的千年。

**【系統】** 三階段誘惑將出現。你的選擇會削弱其黑焰。  
（可沿用雷歐格擋輸入：黑焰必殺可完美格擋。）

### 三階段 · **C6 我拒絕字級爆炸**（爆點必做）

每階段血量門檻（例：100%→進入戰／70%／40%／15% 觸發文戲窗）暫停或半暫停，出選項。

#### 階段 1 · 力量

**魔王**：我給你力量。一擊劈開黑焰。你的村、你的人，瞬間安全。  
**魔王**：你不是慕強。你只是——效率。

| 選項 | 顯示 |
|------|------|
| A | 我拒絕 |
| B | ……聽聽看（仍可聽完再拒，不走壞結局） |

**若選拒絕（或聽完後拒）：**  
（選項 **「我拒絕」** 字級 = 正常 UI ×1.0）  
黑焰外殼裂一圈；魔王攻略降或取消一招。

#### 階段 2 · 復仇

**魔王**：恨我。恨燒村的焰。把恨鍛成刃——比愛鋒利。

| 選項 | 顯示 |
|------|------|
| A | **我拒絕**（字級 ×1.35） |
| B | 我想恨（可選灰線；仍導向可通關，但終章一句不同） |

**拒絕時：** 字已明顯偏大；可輕震動。

#### 階段 3 · 安穩

**魔王**：放下劍。我替你撐封印。你回村。麥田會在。  
**魔王**：永不變強的安穩——這不就是「不慕強權」嗎？

| 選項 | 顯示 |
|------|------|
| A | **我拒絕**（字級 ×1.8～2.0，幾乎搶畫面） |
| B | （若有）我想回家——選後魔王冷笑「那就沉睡」強制接戰鬥傷害波，仍可打；或再跳回 A |

**第三次拒絕演出（必做）：**  
- 「我拒絕」可佔畫面中下部 40% 寬  
- 確認後：黑焰大片剝落  
- 魔王外形收束為「舊至弱者」殘影（獸／人輪廓淡）  
- 進入終段血量

→ `flag.c6_refuse_power / revenge / peace` 分別記錄  
→ 成就「我不慕強權」：三階段皆拒

### 終段

（可再放 1 次黑焰必殺格擋，橫幅可仍用「微末一格」或「微末到底」。）

**魔王（殘影）**：……輕。還是那麼輕。卻不退。

## C6-S6 終章 · 晨光

**【旁白】**  
黑焰潰散的那一刻，法師之塔自塔頂裂開。  
五方聖獸卸下重擔，化作星辰。  
而那隻曾經連劍都拔了三次才拔起的兔子，站在晨光裡——  
不是因為變得多強，是因為從未把心餵給焰。

### 可選尾聲 NPC（依 flag）

| 條件 | 內容 |
|------|------|
| 麥穗重逢／書信 | 「還在啊。」若有碎麥稈：她笑「早說了是氣味」 |
| 灰鬚 | 遠方堡壘旗揚；可不出現，只日誌 |
| 釘釘 | 「鐵還在就好。——別再讓我認第二次葬過的鐵。」 |
| 星讀 | 若空戰魂通關：「你的盤是空的。卻是我見過最亮的。」 |
| 小芽塗鴉 | 日誌插入歪扭兔與獅 |

**【系統】** 通關。冒險仍可繼續（6m：黑焰迴響等）。
