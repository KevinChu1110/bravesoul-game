## 2. 黑焰裂縫（第一個活動框架）

### 定位

> 塔外溢出的「無臉災厄」——每週換皮，**機制組合從庫抽**，不新寫一整套引擎。

### 單人 v1 規則

| 項 | 內容 |
|----|------|
| 入口 | 塔下營地「裂縫」；通關 flag 後出現 |
| 次數 | **每日 3 次有獎**（`RiftSchedule`）；用盡後可練習（金幣×0.35、無經驗） |
| 週焦點 | 四套依週輪替 ★；有獎時金幣×1.5、經驗×1.25 |
| 結構 | **1 活動 Boss**（小怪波可跳，現況直接 Boss） |
| 獎勵 | 金幣、餘燼 flag、首通微量攻擊；不鎖主線 |

### 活動 Boss 輪替（設計 4 套輪，約月循環）

每套 = **簽名 1 + 副 1**（庫 ID），換皮美術即可。

#### 裂縫·甲「怒火」
| | |
|--|--|
| 簽名 | A1 火圈連發（比雷歐更密） |
| 副 | D1 火層：漏閃疊灼燒，3 層大傷 |
| 感覺 | 節奏緊張、反應 |

#### 裂縫·乙「潮噬」（海怒斯精神）
| | |
|--|--|
| 簽名 | E2 時限召喚 3 隻「黑焰刺胞」；2 次出手週期內未清完 → 全場 % 傷 |
| 副 | C3 輪流「物傷減半／技傷減半」相位（用武器類型或技能／普攻切） |
| 感覺 | 清 adds + 換輸出手段 |

#### 裂縫·丙「石像殘響」（皮卡啾精神簡化）
| | |
|--|--|
| 簽名 | B1 三石像輪流無敵，只能打發光的那尊 |
| 副 | A1 落岩；全滅石像後本體短血條 |
| 感覺 | 鎖定目標節奏 |

#### 裂縫·丁「時牢」（拉圖斯精神簡化）
| | |
|--|--|
| 簽名 | H2 炸彈（地面倒數，J 拆除或走開） |
| 副 | A4 安全區（砸地全紅，只留一格） |
| 感覺 | 場地解謎 |

## 6. 實作里程碑建議

| 階段 | 做什麼 |
|------|--------|
| 設計（本檔） | 框架 + 4 套裂縫套件 |
| **實作（怒火）** | ✅ 通關後 hub + 密火圈／灼燒疊層 |
| **實作（輪替）** | ✅ 乙潮噬／丙石像／丁時牢 + hub 四選一 |
| **實作（排程）** | ✅ 週焦點 + 每日有獎 3 次 + 練習局 |
| 連線後 | 裂縫組隊、排行可選 |

### 排程 flag

| flag | 含義 |
|------|------|
| `postgame.rift_day` | 上次刷新的日期 YYYY-MM-DD |
| `postgame.rift_day_used` | 今日已用有獎次數 |
| `postgame.rift_attempt_rewarded` | 本局是否有獎（開戰寫入） |

### 實作 flag（怒火）

| flag | 含義 |
|------|------|
| `game_cleared` / `postgame.rift_unlocked` | 通關、裂縫入口 |
| `postgame.wrath_cleared` | 至少戰勝怒火一次 |
| `postgame.rift_wins` | 裂縫勝場計數 |
| `title.rift_walker` | 勝≥5 稱號 |
| `item.rift_ember` | 餘燼獎勵 |
