# 星途獵場設計

> 主線關卡 **永遠單人**。獵場是主線之外唯一的重複內容。
> 這份文件原本叫 MULTIPLAYER_LOOPS，涵蓋獵場／市集／組隊房三個循環；
> 2026-08-16 後兩者整套砍掉（理由見 [DECISIONS.md](DECISIONS.md)），只剩獵場。

---

## 1. 定位

黑焰溢地邊陲的 **星途獵場**——不是主線地圖。
重複刷材料、養每日循環。

## 2. 解鎖

- 進入騎士堡後（`c1_entered_city`）
- 輿圖／六域岔路「狩獵場」入口

## 3. 規則

| 項 | 規格 |
|----|----|
| 每日有獎場次 | **5**（`HuntSystem`） |
| 每場結構 | **3 波**雜魚（灰燼鼠 → 殘兵 → 焰靈） |
| 中途敗北 | 當波無獎；已過波次保底材料×0～1 |
| 通關獎勵 | 金 + 狩獵材料 + 機率藥水 |
| 用盡後 | 可「練習」：金×0.35、材料稀少 |

## 4. 掉落

| id | 名 | 說明 |
|----|----|----|
| `hunt_hide` | 溢皮 | 基礎材料，賣給溢物回收 |
| `hunt_bone` | 焰骨 | 中階 |
| `hunt_core` | 溢核 | 稀有，日 cap 內有限 |

材料的唯一出口是獵場旁的**溢物回收**（`HuntSystem.recycle_one`）。
市集砍掉之後就沒有玩家之間的流通，這批材料是純粹的金幣來源。

## 5. 主線關卡

維持單人探索／戰鬥。線上只剩：殘影、留言石、蠟燭。
