# NPC · 角色表

> P0 = 3 個月必做 · P1 = 6 個月 · P2 = 有餘力  
> 每人最少：動機、與主角關係、主線掛點、台詞調性。

## 設計原則

1. NPC 要讓世界**有反應**（主線 flag → 台詞變）。  
2. 少而深，勝過多而氣口。  
3. 戰鬥導師／鐵匠／對手都要有「人」不只功能。  
4. 連線相關 NPC 用世界觀包裝（星途觀測者），不要「系統管理員」。
