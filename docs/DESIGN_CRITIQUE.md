> 來源：另一個 AI 對本專案設計的 viral 向評論。  
> 本檔目的：**辯證取捨**——採納什麼、改寫什麼、拒絕什麼、為什麼。  
> 結論已回寫 COMBAT / PROGRESSION / STORY_BIBLE / SCOPE / TECH / SHARE.md。

## 0. 先對齊目標，再談「爆紅」

外部建議預設目標接近：

> solo dev → 內容創作者願意播 → 爆紅

本專案已定案目標是：

> **3～6 個月可完成的完整敘事作品**；可連線但故事為主；延續翠嶺／兔勇者；即時戰鬥手感。

兩者重疊，但不等同。

| | 外部預設 | 我們的現實 |
|--|----------|------------|
| 成功定義 | 容易爆、易 clip | 做完、感人、可玩、可分享 |
| 風險 | 為 viral 加系統導致做不完 | 無高光導致沒人願意播 |
| 正確態度 | 不是全收或全拒 | **用最少開發量換「可被記住的瞬間」** |

**原則：**  
我們不把專案改成「為了 Twitch 而存在的操作秀」；但承認：**沒有任何可 clip 的時刻，敘事再好也難傳播**。解法是在既有骨架上**嵌入少數極致時刻**，而不是重做類型。

## 2. 戰鬥「沒有高光」——採納，但降級為「BOSS 時機層」

### 對方論點
純即時自動 = 直播「看 1 分鐘＝看 10 分鐘」→ 無彈幕動機。

### 同意程度：**高（對 BOSS／宣傳）**；**中（對雜魚）**

- 雜魚戰本來就該是節奏呼吸與養成回饋；**不需要**全程動作遊戲。  
- 致命缺口在：**聖獸／魔王沒有「觀眾會喊一聲」的操作峰**。  
- 若整場改成全時機格擋，會：
  - 偏離「致敬放置即時互毆」的定位  
  - 暴增動畫與關卡調校成本  
  - 與「輕度友善」衝突  

### 我們的定案

```
雜魚：維持即時自動（可快轉）＋輕介入（鎖敵／技能／藥）
BOSS：自動為底 ＋「可反制的必殺」（時機格擋／看破）
宣傳片／實況高光：只靠 BOSS 峰，不靠刷野
```

**3 個月必做：**  
雷歐「王者斬」→ 閃紅／前搖可讀 → 時機輸入 → 成功則**慢鏡「以劍抵爪」**＋反擊窗。  
失敗仍可硬扛（故事模式寬鬆），完美格擋是**秀與成就**，不是唯一通關法。

**6 個月：**  
每隻聖獸至少 1 個專屬「高光機制」（見 SHARE.md），不是每場只換皮。

**明確不做（半年內）：**  
全程魂系式彈反、複雜環境破壞物理、雙搖桿動作。

→ 詳見 [COMBAT.md](COMBAT.md) §「高光層」。

## 3. 劇情反轉——採納「一個」；否決傷溫度的方案

### 對方論點
英雄之旅可預測 → 需要通關前 30 分鐘的愣住時刻。

### 同意程度：**高（需要一個）**；**低（不需要三重反轉）**

可預測結構對**完成度與時程**是優點；缺的是**主題深化的一記**，不是類型顛覆。

### 三方案評析

| 方案 | 評 | 決定 |
|------|-----|------|
| A. 麥穗其實已死，後面是幻覺 | 煽情強，但**直接傷害「溫暖、flag、等待」的人格**；易變廉價悲劇 | ❌ 不用作主線核心 |
| B. 鏽劍是千年前至弱者之劍，釘釘知情不說 | 好伏筆、低成本、強化器軸敘事 | ✅ **副線反轉／中段揭露** |
| C. 魔王＝前任至弱者，為維持封印而選擇「變強」 | **完美咬合主題**；讓最終戰是哲學而非只砍血條 | ✅ **主反轉** |

### 我們的定案（單一主反轉＋一條器伏筆）

**主反轉（C，通關前約 20～40 分鐘，塔中層揭露）：**

> 魔王曾是第一位走到塔頂的「至弱者」。  
> 為了讓封印多撐千年，祂接受了黑焰、以野心為薪柴——  
> 「變強」成了祂守護世界的方式。  
> 預言沒寫錯；寫漏了代價。  
> 你的拒絕，不是天真，是**另一條路**：不靠吞噬野心來守護。

**副伏筆（B，釘釘／典籍碎片，可在 C1～C3 漏）：**

> 微末之刃的芯，是古至弱者的殘鐵。釘釘重鍛時認出紋路，只說「別弄丟」。塔中才與魔王本體連結。

**麥穗：** 保持生還可能（或失聯後重逢）。若要虐，用「差點被黑焰誘惑」灰線，**不要**整段幻覺騙玩家——那會污染信任與溫度。

→ 詳見 [STORY_BIBLE.md](STORY_BIBLE.md) 反轉節。

## 4. 聚魂 gacha stigma——採納「去抽卡化」

### 對方論點
獨立遊戲受眾對 gacha 標籤過敏；每日限次／付費貨幣是紅線。

### 同意程度：**很高**

本作為單機敘事＋itch/Steam 受眾，**不該背抽卡罵名**。  
舊 bot 的「每日免費抽」是 Discord 日活設計，**不該原樣搬進單機**。

### 我們的定案

| 舊設計 | 新設計 |
|--------|--------|
| 每日免費抽＋金幣抽 | **探索取得星曜殘片／星屑** |
| 隨機品質為主興奮 | **觀星儀式**：結果受**足跡**影響（進度、域、關鍵選擇） |
| 合成 3 合 1 | **保留**（輕隨機，非付費 gacha） |
| UI「抽」「保底」 | UI「觀星」「凝魂」；**無付費幣、無每日限次牆** |

聚魂殿＝敘事空間（星讀），不是轉蛋機。  
興奮感來自：**找到隱藏星屑、第一次神階觀星演出**，不是「今天抽到了嗎」。

→ 詳見 [PROGRESSION.md](PROGRESSION.md) 戰魂節改寫。

## 5. 長度 3 小時——部分採納

### 對方論點
3h 難獲媒體；要 6～8h＋二周目。

### 同意程度：**中高**

- 極致短篇可以紅，但要**美術／音樂天花板**，solo 半年難賭。  
- 原 SCOPE「3～6h」偏樂觀且偏短。  

### 我們的定案

| 里程碑 | 目標長度 | 內容 |
|--------|----------|------|
| 3 個月垂直可通關 | **5～7 小時** | 仍 3 完整域＋塔；**減少「過場壓縮感」**，每域有肉 |
| 6 個月完整版 | **8～12 小時**主線＋支線 | 六域＋隱藏要素 |
| 通關後 | **黑焰迴響**（輕 NG+） | 見 SHARE；非必須肝 |

不為了時長灌水刷野；用**域機制差異＋支線＋反轉塔層**拉長。

Speedrun 計時器、隱藏 BOSS：標 **P1/P2**，不擋 3m 主線，但**設計預留**（無無效操作、可 skip 演出）。

## 6. 平台：Web 優先——採納策略；**不**因此立刻棄 Godot

### 對方論點
itch 連結即玩 > Steam 先；Godot Web 載入差 → 改 Phaser。

### 同意程度：策略 **高**；換引擎 **低（現階段）**

| 判斷 | 說明 |
|------|------|
| itch 先於 Steam 完整營運 | ✅ 採納：更容易給創作者連結 |
| 「5 秒進遊戲」 | 理想；實務可 **下載版＋可選 Web** |
| 現在改 Phaser | ❌ 成本高，且你要場景敘事＋BOSS 演出，Godot 更合適 |
| Godot Web | 可作 demo 切片；完整作以 **原生 build 上傳 itch** 亦可 viral |

### 我們的定案

```
3m：本機／itch 下載 build（免費或 PWYW）為主
    另可 export 小 demo Web（僅 C0+雷歐）做「即點即玩預告」
4–6m：依反響再 Steam
引擎：維持 Godot 4，不因一篇建議雙重寫
```

「創作者門檻」用：**檔小、免安裝器、一鍵、30 分鐘內到雷歐高光** 解決，不一定要瀏覽器。

## 9. 最關鍵一問：觀眾憑什麼記住？

外部逼問很好。我們的答案應是**一句可搜尋的記憶**，而不是功能列表：

> **「一隻拿鏽劍的兔子，格擋了獅子王的必殺，後來發現魔王曾是和牠一樣的至弱者。」**

可拆成三個可 clip／可截圖支柱：

| 支柱 | 時刻 | 載體 |
|------|------|------|
| 視覺 meme | 小兔扛劍進城／對獅 | 封面、短影音前 3 秒 |
| 操作高光 | 以劍抵爪慢鏡 | 直播彈幕、預告中段 |
| 敘事重擊 | 塔中「原來你也是」 | 通關討論、長影片高潮 |

若只能做一個極致：**雷歐格擋鏡頭**（獲客）＋**魔王認同反轉**（口碑）必須有；其餘皆加成。

## 10. 風險：聽了建議反而做壞

| 陷阱 | 避免 |
|------|------|
| 為了操作秀放棄溫度 | 雜魚不強制彈反 |
| 反轉害死麥穗信任 | 不用幻覺麥穗主線 |
| 去 gacha 後戰魂無趣 | 用探索發現與足跡敘事補興奮 |
| 為 8 小時灌水 | 只加有機制的域與塔層 |
| 換引擎空轉兩月 | 不換 |
| 幻想爆紅 | 成功線 1：做完；線 2：被播；線 3：爆——分開看 |

## 11. 結論（給 Kevin）

- 外部建議 **診斷準**（缺高光、缺反轉、gacha 雷、發行順序）。  
- 處方需 **削成 solo 可吞的劑量**：BOSS 時機層、一個主題級反轉、戰魂探索化、itch 優先。  
- 敘事骨架 **A 級要守**；viral 元素從 C 拉到 **B＋** 就夠用——先求「必被記住」，再求「爆」。
