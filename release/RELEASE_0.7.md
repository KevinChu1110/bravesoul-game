# 翠嶺·兔勇者 0.7.0

## 這包能做什麼

- **主線 C0→C6 可通關**（約數小時）：村、騎士堡／雷歐、霧隱／信／白霧、道場／阿波、可選疾影／石拳、塔／魔王／終章  
- **通關後**：黑焰裂縫、稱號牆、黑焰迴響 NG+  
- **養成**：器（鍛造）／魂（觀星）／招（技能）  
- **探索**：六域地圖密度、小芽木劍支線、存檔石回血  
- **系統**：Esc 暫停（進度／備份匯出匯入）、標題語言切換、地區 BGM  

## 下載檔

`dist/uploads/`

- `Cuiling-BraveSoul-0.7.0-win.zip`
- `Cuiling-BraveSoul-0.7.0-mac.zip`
- `Cuiling-BraveSoul-0.7.0-linux.zip`

## 上傳 itch

1. 開專案頁 → Edit game → Distribution  
2. 上傳三個 zip（或至少 win+mac）  
3. 文案貼 `release/ITCH_PAGE.md`
